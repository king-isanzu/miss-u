MISS YOU — LUXURY LOVE WEBSITE
================================

Files:
- index.html  : website structure and English love messages
- style.css   : responsive luxury dark theme, 3D-inspired CSS chocolate drink and rose, motion effects
- script.js   : surprise countdown, hearts/confetti, sound toggle
- assets/     : place any local photos or music here if you want to customize it

HOW TO OPEN IN VISUAL STUDIO CODE
1. Extract the ZIP file.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select the extracted "miss_you_luxury_website" folder.
4. Open index.html.
5. Recommended: install the "Live Server" extension, right-click index.html, and choose "Open with Live Server".
   Or open index.html directly in your browser.

IMPORTANT
- This is a front-end website using HTML, CSS, and JavaScript. Java and C++ are not normally used for browser page design.
- The optional background piano audio uses an online URL and needs internet access. Browsers require you to tap "Sound off" to start audio.
- Google Fonts also need internet access; fallback fonts will be used if offline.
- Change "Aziz" in index.html to another name if you wish.
- The CSS-made chocolate drink and rose are decorative 3D-inspired artwork, so the core visual does not require image downloads.
